# Java ATM Management System

A Java-based ATM Management System developed using object-oriented programming concepts.

## Features
- User authentication
- Account management
- Deposit and withdrawal operations
- Transaction handling
- Savings and checking accounts
- Exception handling
- GUI support

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Purpose
This project was developed as part of a university programming course to demonstrate Java application development and banking system simulation.
